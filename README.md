# Metro Bug Reproducer

Minimal Kotlin Multiplatform project to reproduce a bug where KSP-contributed bindings are not visible to the Metro compiler plugin on non-JVM/Android targets.

## Bug Details

**Issue**: KSP-contributed bindings (via `@ContributesIntoSet`) are not visible to the Metro compiler plugin on non-JVM/Android targets, causing compilation failures.

**Affected Versions**:
- Metro: 0.9.2
- Kotlin: 2.3.20-dev-7692
- KSP: 2.3.4

**Note**: This issue may be caused by incompatibility between the dev version of the Kotlin compiler (2.3.20-dev-7692) and KSP. Additionally, metro has not been tested with this version of the compiler.

**Affected Targets**: All non-JVM targets (iOS, and presumably JS and WASM) - JVM/Android works correctly.

## Technical Details

Circuit's KSP processor generates `@ContributesIntoSet` annotations for Presenter and UI factories. While these bindings compile and work correctly on JVM/Android targets, the Metro compiler plugin cannot resolve them on non-JVM targets (iOS, and presumably JS and WASM), resulting in missing dependency injection bindings at compile time.

The bindings are generated by KSP but are not visible to Metro's IR plugin during compilation of non-JVM source sets.
